# Brand

`icon.png` (256x256) and `icon@2x.png` (512x512) are an original, generic
design made for this project: a dual monitor showing a waveform on one screen
and a red tally border on the other. It is not the Blackmagic Design logo.

The copies Home Assistant actually reads live in
`custom_components/blackmagic_smartview/brand/`. This folder holds the same
files as source material for anyone forking the project.

To use different artwork, replace the files in
`custom_components/blackmagic_smartview/brand/` with your own PNGs of the same
names and sizes and restart Home Assistant. The Blackmagic Design, SmartView
and SmartScope names and marks belong to Blackmagic Design.
